# EON

## Vision

EON (Evolving Operating Nexus) is a modular, local-first AI operating system that will eventually become a Jarvis-like assistant capable of understanding, reasoning, planning, remembering, and controlling the user's computer.

---

## Core Principles

- Local-first
- Modular architecture
- Service-based design
- Long-term maintainability
- Explainable code
- Extensible modules
- No hardcoded behavior

---

## Current Architecture

Current modules include:

- Brain
- Identity
- Memory
- Recall
- Store
- Context
- Perception
- Conversation
- Planner
- Reasoning
- Intent
- Tools
- Execution

---

## Coding Rules

- Never replace existing architecture unless necessary.
- Extend modules instead of rewriting them.
- Keep classes small and single-purpose.
- Prefer composition over inheritance.
- Always update documentation when architecture changes.

---

## Long-Term Goal

Transform EON into a personal AI operating system similar in spirit to JARVIS:

- Understand the user
- Remember permanently
- Control desktop applications
- Browse the web
- Execute code
- Manage files
- Learn continuously
- Become proactive
- Support voice conversation
- Support vision
- Support autonomous task execution
