# Architecture Documentation

## Purpose

This directory contains the architectural documentation for EON.

The documents in this directory describe how the system is organized, why major design decisions were made, and how the individual modules interact.

This documentation is intended for contributors, maintainers, and future developers.

# Architectural Principles

The architecture follows the principles defined in:

- Separation of Concerns
- Dependency Inversion
- Single Responsibility
- Open/Closed Principle
- Composition over Inheritance
- Explicit Lifecycle Management
- Provider Pattern
- Interface-Driven Design
