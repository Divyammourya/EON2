# Project

EON is a modular, local-first personal AI assistant designed to understand, reason, remember, and interact with the user's computer.

The project focuses on building an extensible AI architecture rather than a simple chatbot.

---

# Vision

Build a fully autonomous desktop AI capable of:

- Understanding natural language
- Long-term memory
- Reasoning before acting
- Planning complex tasks
- Controlling the local computer
- Learning from interactions
- Remaining completely local and privacy-focused

---

# Goals

- Modular architecture
- Provider-independent AI
- Local-first execution
- Semantic long-term memory
- Extensible tool system
